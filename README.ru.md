# LocalCanvas

[English](README.md) · **Русский** · [日本語](README.ja.md)

Политика безопасности, заметки для участников проекта и список изменений есть
только на английском: SECURITY.md, CONTRIBUTING.md и CHANGELOG.md.

**ComfyUI — чтобы собирать воркфлоу. LocalCanvas — чтобы ими пользоваться.**

LocalCanvas — это приложение для Android к тем воркфлоу ComfyUI, которые у вас
уже есть. Выберите воркфлоу на телефоне, напишите промпт, добавьте картинку или
видео, если воркфлоу их принимает (см. [Известные ограничения](#известные-ограничения)),
и нажмите «Сгенерировать». Граф узлов вы не видите никогда.

    Приложение на Android
        │  ваш Wi-Fi / локальная сеть
        ▼
    LocalCanvas Gateway    ← единственное, что видно в сети
        │  localhost
        ▼
    ComfyUI  →  GPU

- **Локально.** Всё работает на вашем компьютере и в вашей сети.
- **Работает с вашим ComfyUI.** В него ничего не устанавливается.
- **Интерфейс на Android**, который показывает каждый воркфлоу как простую форму.
- **Импорт и синхронизация воркфлоу** из папки воркфлоу вашего ComfyUI.
- **Никакого облака LocalCanvas и никакой учётной записи.**

**Чем он не является** — намеренно и насовсем: ни учётных записей, входа и
аутентификации; ни облачной синхронизации, удалённого доступа через интернет и
генерации в облаке; ни магазина плагинов и SDK; ни редактора воркфлоу и графа
узлов; ни шлюза, угадывающего входы воркфлоу на ходу; ни ИИ-улучшателя промптов
и встроенной LLM; ни истории в базе данных и серверной медиатеки; ни
многопользовательского режима; ни Kubernetes; ни приложения для iOS и
веб-интерфейса.

## Что нужно

- **Windows 10 или 11.**
- **PowerShell 7 или новее** (`pwsh`). Windows PowerShell 5.1 не поддерживается.
  Установка: `winget install --id Microsoft.PowerShell`.
- **Python 3.10 – 3.13, уже установленный** (с <https://www.python.org/downloads/>).
  Setup найдёт его и соберёт на нём собственное окружение LocalCanvas.
- **Уже работающий ComfyUI.** ComfyUI ещё нет? Необязательный
  [bootstrap Minimal](docs/user-guide.ru.md#2-где-взять-comfyui) его установит —
  моделей он не скачивает и окружение Python не собирает.
- **Google Chrome или Microsoft Edge** — чтобы конвертировать воркфлоу,
  сохранённые в ComfyUI через **Save**.
- **Телефон на Android** (Android 7.0 или новее) в той же сети.
- **git** — чтобы склонировать этот репозиторий.
- Только если собираете приложение сами: Flutter и Android SDK
  (см. [Приложение для Android](#приложение-для-android)).

## Быстрый старт

В окне PowerShell 7 на компьютере, где работает ComfyUI:

```powershell
git clone https://github.com/shinKatana0/LocalCanvas.git LocalCanvas
cd LocalCanvas
pwsh .\scripts\setup.ps1
pwsh .\scripts\start.ps1
```

- Setup задаст два коротких вопроса — запускаете ли вы ComfyUI сами и где лежит
  папка вашего ComfyUI (та, где `main.py`, или папка портативной сборки), — и сам
  напишет конфигурацию. YAML вы не правите. (Третий вопрос будет, только если он
  не найдёт вашу папку воркфлоу.) Оба вопроса разобраны в
  [руководстве](docs/user-guide.ru.md#3-установка-и-запуск-localcanvas).
- Перед `start.ps1` запустите ComfyUI (если только вы не поручили его запуск
  LocalCanvas).
- Первый запуск найдёт ваши воркфлоу и предложит их импортировать.
- В конце он напечатает QR-код для телефона.

Остаётся ещё один шаг: поставить приложение на телефон — см.
[Приложение для Android](#приложение-для-android).

## Каждый день

```powershell
pwsh .\scripts\start.ps1
```

Это команда на каждый день. Не закрывайте её окно, пока пользуетесь телефоном:
если закрыть окно, LocalCanvas тоже остановится.

При каждом запуске она проверяет папку воркфлоу вашего ComfyUI. Проверка только
читает ваши файлы — ничего не конвертирует и ничего не пишет.

- **Ничего не изменилось** — `Workflows: unchanged - nothing new and nothing edited`,
  и LocalCanvas запускается.
- **Что-то новое или изменённое** — она спросит `Sync workflows now? [Y/n]`.
  Enter означает «да».
- Сама она синхронизацию не делает никогда, а сеанс, в котором некому ответить
  (задача планировщика, шаг CI, конвейер, оболочка с `-NonInteractive`), ни о
  чём не спрашивает: называет команду и запускается как есть.

`pwsh .\scripts\stop.ps1` останавливает то, что запустил LocalCanvas;
`pwsh .\scripts\status.ps1` показывает, что сейчас работает.

## Как добавить или изменить воркфлоу

1. Создайте или измените воркфлоу в ComfyUI и сохраните его через **Save** (или
   **Export (API)** — годится и то и другое).
2. Если LocalCanvas запущен, остановите его: `pwsh .\scripts\stop.ps1`.
3. При запущенном ComfyUI (если только вы не поручили его запуск LocalCanvas)
   выполните `pwsh .\scripts\start.ps1`.
4. Он сообщит `Workflows: 1 new` (или `changed`) и спросит `Sync workflows now? [Y/n]`.
5. Если приложение уже было открыто, а воркфлоу в списке нет, нажмите
   **«Обновить список»** (↻) вверху экрана **«Выберите воркфлоу»**.

В фоне за папкой никто не следит: изменения подхватываются, когда вы запускаете
`start.ps1` или синхронизируете сами:

```powershell
pwsh .\scripts\sync-workflows.ps1 -DryRun    # показать, что будет импортировано; ничего не писать
pwsh .\scripts\sync-workflows.ps1            # импортировать сейчас
pwsh .\scripts\start.ps1 -SyncWorkflows      # синхронизировать всё изменённое без вопроса и запуститься
```

Воркфлоу, который LocalCanvas не может прочитать уверенно, откладывается как
`NEEDS_REVIEW`, а не угадывается — что с ним делать, написано в
[руководстве](docs/user-guide.ru.md#4-ваши-воркфлоу).

## Приложение для Android

**Где взять APK.** Если в этом репозитории опубликован релиз, скачайте APK со
страницы **Releases**. Или соберите его сами с Flutter и Android SDK, из папки
`app/`:

```powershell
flutter pub get
flutter build apk --release --split-per-abi
```

Большинству телефонов нужен APK `arm64-v8a`. Android попросит разрешить
установку из той программы, которой вы открыли файл, — это ручная установка, а
не из магазина. APK подписан отладочным ключом (тестовая подпись), поэтому перед
установкой сборки, собранной в другом месте, удалите LocalCanvas. Подробности —
в [руководстве](docs/user-guide.ru.md#5-установка-приложения).

**Подключение.** Отсканируйте QR-код, который напечатал `start.ps1`, введите
адрес (`192.0.2.42`, `192.0.2.42:7801` или `http://192.0.2.42:7801` — с адресом
вашего компьютера) или выберите компьютер из списка, который приложение найдёт в
сети, если ваш роутер пропускает обнаружение. Подробнее:
[Подключение по Wi-Fi](docs/user-guide.ru.md#6-подключение-по-wi-fi).

**Брандмауэр Windows.** При первом запуске `start.ps1` Windows может спросить,
разрешить ли ему доступ к сети: разрешите только **частные сети** (Private
networks). Входа по паролю у шлюза нет, поэтому держите его только в доверенной
домашней сети. Если телефон не видит компьютер, обычно дело в брандмауэре.

## Приватность

Никакой телеметрии, аналитики, отчётов о сбоях, учётных записей и генерации в
облаке. Приложение общается только с вашим шлюзом, а шлюз — только с вашим
ComfyUI. Это обещание о собственном коде LocalCanvas, **а не о сторонних
custom nodes ComfyUI**, которые могут делать всё, что в них написали их авторы, —
см. [SECURITY.md](SECURITY.md).

## Известные ограничения

- Сторона компьютера — **только Windows**.
- Вручную сопровождающий проверил подключение и генерацию на одном складном
  телефоне по Wi-Fi с настоящим ComfyUI. Автоматически этот путь не покрыт
  ничем.
- Отправка картинки или видео с телефона пока не подтверждена как работающая.
- Перевод промпта и обнаружение по mDNS на телефоне проверялись только на
  имитациях.
- Воркфлоу, отложенному как `NEEDS_REVIEW`, нужен человек, который решит, что в
  нём показывать.

Подробнее о том, что проверялось, — в [руководстве](docs/user-guide.ru.md#1-прежде-чем-начать).
Что-то не работает? Запустите `pwsh .\scripts\doctor.ps1`, потом загляните в
раздел [Когда что-то не так](docs/user-guide.ru.md#13-когда-что-то-не-так).
