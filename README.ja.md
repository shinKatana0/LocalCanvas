# LocalCanvas

[English](README.md) · [Русский](README.ru.md) · **日本語**

**アプリの表示言語は英語とロシア語だけです。** 日本語のロケールはありません。
Windows のトレイランチャーにも表示言語の選択はなく、見出しや本文、「Run
setup」のような独自のボタンはつねに英語です（[Cancel]・[Close] だけは
Windows 自身が用意する標準ボタンで、Windows の表示言語に従います）。この文書は
日本語ですが、画面に出る文言は英語（またはロシア語）のままです。以下で画面の
項目を引用するときは、英語の表記をそのまま示し、意味を添えます。

セキュリティポリシー、コントリビューションの手引き、変更履歴は英語のみです:
SECURITY.md、CONTRIBUTING.md、CHANGELOG.md。

**ワークフローを組むのは ComfyUI。使うのは LocalCanvas。**

LocalCanvas は、すでにお持ちの ComfyUI ワークフローのための Android アプリです。
スマートフォンでワークフローを選び、プロンプトを書き、ワークフローが受け付けるなら
画像や動画を足して（[既知の制限](#既知の制限)を参照）、「Generate（生成）」を
押します。ノードグラフを見ることは一度もありません。

    Android アプリ
        │  あなたの Wi-Fi / LAN
        ▼
    LocalCanvas Gateway    ← ネットワーク上に出るのはこれだけ
        │  localhost
        ▼
    ComfyUI  →  GPU

- **ローカル優先。** すべてがあなたの PC と、あなた自身のネットワークの中で動きます。
- **今お使いの ComfyUI で動きます。** ComfyUI には何もインストールしません。
- **Android のフロントエンド。** 各ワークフローをシンプルなフォームとして表示します。
- **ワークフローの取り込みと同期。** ComfyUI のワークフローフォルダーから行います。
- **LocalCanvas のクラウドもアカウントもありません。**

**これは何ではないか** —— 意図してそうしており、今後も変わりません: アカウント、
ログイン、認証はありません。クラウド同期、インターネット越しのリモートアクセス、
クラウド生成もありません。プラグインのマーケットプレイスや SDK、ワークフローや
ノードグラフのエディタ、実行時にワークフローの入力を推測するゲートウェイ、AI による
プロンプト改善や組み込み LLM、データベースに残る履歴やサーバー側のメディア
ライブラリ、マルチユーザー対応、Kubernetes、iOS アプリ、Web フロントエンドも
ありません。

## 必要なもの

- **Windows 10 または 11。**
- **すでに動いている ComfyUI。** まだ ComfyUI がない場合は、任意の
  [Minimal ブートストラップ](docs/user-guide.ja.md#1-インストール)で入れられ
  ます —— モデルはダウンロードせず、Python 環境も作りません。
- **PowerShell 7 以降** (`pwsh`)。Windows PowerShell 5.1 はサポートしません。
  `LocalCanvas.exe` が自分で開いた PowerShell のウィンドウで初回セットアップを
  行うので、この手順のために自分で `pwsh` を開く必要はありません。無ければ
  `winget install --id Microsoft.PowerShell`。
- **インストール済みの Python 3.10 – 3.13**（<https://www.python.org/downloads/>
  から）。セットアップは見つけた Python 上に LocalCanvas 専用の環境を作ります。
- **Google Chrome または Microsoft Edge。** ComfyUI の **Save** で保存した
  ワークフローを変換するのに使います。
- 同じネットワークにある **Android スマートフォン**（Android 7.0 以降）。
- Android アプリを自分でビルドする場合のみ: **Flutter**、**Android SDK**
  （[Android アプリ](#android-アプリ)を参照）。コマンドライン（下記）にも
  **git** は要りません —— zip の中にすでに `scripts\` が入っています。
  `git` が必要なのは、zip をダウンロードする代わりにこのリポジトリを
  クローンするとき、またはアプリをビルドするときだけです。

## ダウンロード

このリポジトリの **Releases** ページから（公開されたら）:

- **`LocalCanvas-0.2.0-windows-x64.zip`** —— Windows 用パッケージ。単体で動く
  `LocalCanvas.exe` が 1 つ入っています。実行するマシンに .NET のインストールは
  要りません。
- **`LocalCanvas-0.1.5-arm64-v8a.apk`** —— Android アプリ。この版では変わって
  おらず、このゲートウェイでそのまま使えます。
  [Android アプリ](#android-アプリ)を参照してください。

`LocalCanvas.exe` は現在署名されていません —— 下記の **Smart App Control** を
参照してください。

## クイックスタート

1. LocalCanvas を動かす PC で ComfyUI を起動します —— セットアップで
   LocalCanvas に起動を任せる予定（手順 4）でなければ。
2. `LocalCanvas-0.2.0-windows-x64.zip` をダウンロードし、その同じ PC の
   どこかに展開します。
3. 展開した `LocalCanvas` フォルダーの中にある `LocalCanvas.exe` をダブルクリック
   します。
4. 初回は、セットアップを実行するかを尋ねられます —— **Run setup** を選んで
   ください。PowerShell のウィンドウが開き、短い質問を 2 つします（ComfyUI を
   自分で起動するか、そして ComfyUI のフォルダーがどこにあるか）。セットアップが
   終わると、LocalCanvas は自分で続きを進め、ワークフローを見つけて同期するか
   尋ねます。
5. スマートフォンにアプリを入れます —— [Android アプリ](#android-アプリ)を参照
   してください。
6. トレイに新しく現れたアイコンを右クリックします —— Windows 11 では隠れている
   アイコンの **^** の下にあることがあります —— そして **Open status** を選びます:
   そこにアドレスとペアリング用の QR コードがあります。
7. アプリを開いて QR コードを読み取り（またはアドレスを入力し）、ワークフローを
   選んでプロンプトを書き、**Generate** を押します。

これで LocalCanvas はシステムトレイに常駐します。各手順、トレイのアイコンと
メニュー、うまくいかないときにすることは
[ユーザーガイド](docs/user-guide.ja.md)で詳しく説明しています。

**Smart App Control。** `LocalCanvas.exe` にはコード署名がありません。
Smart App Control（Windows セキュリティの設定）が有効な PC では、Windows は
これを問答無用でブロックします —— 「実行」を選べるダイアログは出ません。
[コマンドラインでの手順](docs/user-guide.ja.md#14-コマンドラインでの詳しい操作)は
Microsoft が署名した `pwsh` を通るので、Smart App Control の影響を受けず問題なく
動きます。

## 毎日の使い方

もう一度 `LocalCanvas.exe` をダブルクリックするか、そのままトレイに置いておいて
ください —— 2 回目の起動は 2 つめを立てるのではなく、1 つめの Open status
ウィンドウを前面に出します。トレイのアイコンが今の状態を示します: 緑のチェックは
LocalCanvas が使える状態、黄色のスピナーは起動中、赤い×はゲートウェイが
落ちていることを表します。アイコンを**右クリック**すると Restart Gateway、
Sync workflows、Open status、Exit が出ます。メニューとアイコンの全体は
[ユーザーガイド](docs/user-guide.ja.md#4-トレイ)にあります。

トレイのメニューで **Exit** を選ぶと LocalCanvas が起動したものは止まります。
LocalCanvas が起動していない外部の ComfyUI は動いたままです。アイコンが赤い
×を示しているときは、右クリックして **Restart Gateway** を選んでください。

## ワークフローを追加・変更する

1. ComfyUI でワークフローを作るか編集し、**Save** で保存します（**Export (API)**
   でも構いません。どちらも使えます）。
2. ComfyUI を起動した状態で（LocalCanvas に起動を任せた場合を除く）LocalCanvas を
   起動するか、動かしたままにします。
3. 変更が見つかると **Sync now** を提案してきます。または、いつでもトレイの
   アイコンを右クリックして **Sync workflows** を選べます。
4. アプリをすでに開いていて、そのワークフローが一覧にない場合は、
   **Choose a workflow**（ワークフローを選ぶ）画面の上にある
   **Refresh the list**（一覧を更新、↻）をタップします。

バックグラウンドでフォルダーを見張るものはありません。変更が取り込まれるのは、
次の起動時、**Sync workflows** を使ったとき、またはコマンドラインからのときです
（[ユーザーガイド](docs/user-guide.ja.md#6-ワークフローの追加と更新)に両方の
やり方があります）。

確信をもって読めないワークフローは、推測せずに `NEEDS_REVIEW` として保留します
—— どうすればよいかは
[ユーザーガイド](docs/user-guide.ja.md#6-ワークフローの追加と更新)にあります。

## Android アプリ

**APK を手に入れる。** このリポジトリがリリースを公開していれば、その
**Releases** ページから APK をダウンロードできます。または Flutter と Android SDK
を使って、`app/` で自分でビルドします:

```powershell
flutter pub get
flutter build apk --release --split-per-abi
```

たいていのスマートフォンに必要なのは `arm64-v8a` の APK です。Android は、ファイルを
開いたアプリからのインストールを許可するか尋ねます —— ストアではなく手動で入れる
（サイドロード）からです。APK はデバッグ鍵で署名された（テスト用の署名の）ビルド
なので、別の場所でビルドされたものを入れる前に LocalCanvas をアンインストールして
ください。詳しくは
[ユーザーガイド](docs/user-guide.ja.md#5-スマートフォンをつなぐ)を参照
してください。

**接続する。** トレイの **Open status** を開くと、アドレスとペアリング用の
QR コードが出ます（コマンドラインでも同じ QR コードが自分のウィンドウに出ます）。
それを読み取るか、アドレスを入力するか
（`192.0.2.42`、`192.0.2.42:7801`、`http://192.0.2.42:7801` —— あなたの PC の
アドレスで）、ルーターが探索を通す環境なら、アプリがネットワーク上で見つけた一覧
から PC を選びます。詳しくは
[スマートフォンをつなぐ](docs/user-guide.ja.md#5-スマートフォンをつなぐ)を参照
してください。

**Windows ファイアウォール。** LocalCanvas が初めてゲートウェイを起動したとき、
Windows がネットワークへのアクセスを許可するか尋ねることがあります。許可するのは
**プライベート ネットワーク**（Private networks）だけにしてください。ゲートウェイ
にはログインがないので、信頼できる家庭のネットワークだけで使ってください。
スマートフォンから PC に届かないとき、原因はたいていファイアウォールです。

## プライバシー

LocalCanvas 自身のコードには、独自のアナリティクスや使用状況のテレメトリ、
クラッシュレポート、アカウント、クラウド生成は含まれていません。アプリが話す
相手はあなたのゲートウェイだけで、ゲートウェイが話す相手はあなたの ComfyUI
だけです。QR コードの読み取りには、Android アプリが Google ML Kit を使って
います —— この機能には、Google 提供のコンポーネントが含まれ、それら自身の
ネットワークやデータの扱いを持つことがあります。Windows のトレイランチャーも
これに何も加えません —— それ自身がおこなう通信は、ゲートウェイと、監視している
ComfyUI（自分で起動したかどうかを問いません）への loopback のヘルスチェック
だけです。これは LocalCanvas 自身のコードについての約束であり、
**サードパーティの ComfyUI カスタムノードや上記の Google のコンポーネントに
ついての約束ではありません**。それらは、作者や提供元が書いたとおりのことを
何でもできます —— [SECURITY.md](SECURITY.md) を参照してください。

## 既知の制限

- PC 側は **Windows のみ**です。
- `LocalCanvas.exe` には署名がありません。Smart App Control が有効な PC では
  ブロックされ、コマンドラインでの手順（上のクイックスタートを参照）が必要です。
- 手作業では、メンテナーが折りたたみスマートフォン 1 台で、Wi-Fi 経由で本物の
  ComfyUI を相手に、ペアリングと生成を確認しています。この経路を自動で確かめる
  ものはありません。
- 画像や動画のアップロードは、スマートフォンから動くことがまだ確認できていません。
- プロンプトの翻訳と、mDNS による探索がスマートフォンに届くことは、模擬環境で
  しか試していません。
- `NEEDS_REVIEW` として保留されたワークフローは、何を表示するかを人が決める必要が
  あります。

何が確かめられているかの詳細は
[ユーザーガイド](docs/user-guide.ja.md#1-インストール)にあります。うまくいかない
ときは
[うまくいかないとき](docs/user-guide.ja.md#13-うまくいかないとき)を参照して
ください。
